# 共享厨房预约插件实现计划

**目标** 让用户提前设置日期、时段、厨房顺序和用餐人数，并由 Chrome 按北京时间执行一次预约。

**设计** 使用 Manifest V3、本地存储和站点内容脚本。后台提前准备专用标签页，前台标签页按计划时间执行，后台负责对一次提交进行授权。图形弹窗显示计划、建议开机时段和结果。

- [x] 用已满时段验证表单、时段限制、须知倒计时和确认页，核对公开前端的控件标记。
- [x] 先验证放号日期、开放时段、优先级、容量和重启后的计划状态。
- [x] 实现设置弹窗、后台唤醒、页面交互和回执判断。确认状态未知时保留一次提交记录。
- [x] 用浏览器加载插件，演练约满、协议倒计时、防重复提交和成功回执。校园生产环境演练停在确认前。
- [x] 提交代码、安装说明和自动测试，推送到仓库的默认分支，核对远程提交。
